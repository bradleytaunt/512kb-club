How do I join The 512KB Club?

If you're interested in getting your site added to The 512KB Club, all you need to do is follow these instructions:

  1. Check your website's total size (not transferred!) using Firefox's Network tab. Make sure you have cache disabled and ensure all resources have loaded. You might need to scroll the entire page if any assets are loaded in dynamically.
  2. If your site satisfies this requirement, add it to the existing _data/sites.yml file (following the same format as other members) and open a PR or submit a patch via email if you prefer.
  3. I will then review your patch and merge it into master. Once merged, your site will be added to the list.

Note: I reserve the right to not add sites based on whether I think they're suitable to be added or not. Please DO NOT use tickets to submit websites.
